API Documentation

This is a lightweight web service, (REST interface), which provides an easy way to access the website's data. An API (Application programming interface) is a protocol intended to be used as an interface by software components to communicate with each other.

Our API supports many methods, so there should not be a problem coding some nice applications.

API Endpoints Overview

  • List Movies
  • Movie Details
  • Movie Suggestions
  • Movie Parental Guides

Common Response Structure

All the API endpoints return the same data structure as below:

Returned KeyDescriptionExample
statusThe returned status for the API call, can be either 'ok' or 'error'ok
status_messageEither the error message or the successful messageQuery was successful
dataIf 'status' is returned as 'ok' the API query results will be inside 'data'{...}

List Movies

Used to list and search through out all the available movies. Can sort, filter, search and order the results.

HTTP Method: GET

Endpoints:

  • https://flixapi.gametrader.my/api/v2/list_movies.json
  • https://flixapi.gametrader.my/api/v2/list_movies.jsonp
  • https://flixapi.gametrader.my/api/v2/list_movies.xml

Parameters:

ParameterRequiredTypeDefaultDescription
limitNoInteger (1-50)20The limit of results per page.
pageNoInteger (Unsigned)1Used to see the next page of movies.
qualityNoStringAllFilter by quality (e.g., 480p, 720p, 1080p, 2160p, 3D).
minimum_ratingNoInteger (0-9)0Filter by minimum IMDb rating.
query_termNoString0Movie search term (Title/IMDb Code, Actor, Director).
genreNoStringAllFilter by genre (See IMDb for full list).
sort_byNoStringdate_addedSort results by (title, year, rating, peers, seeds, download_count, like_count, date_added).
order_byNoStringdescOrder results (desc, asc).
with_rt_ratingsNoBooleanfalseInclude Rotten Tomatoes ratings.

Examples:

URLDescription
https://flixapi.gametrader.my/api/v2/list_movies.json?quality=3DReturns the latest 20 3D movies (JSON format).
https://flixapi.gametrader.my/api/v2/list_movies.xml?sort_by=seeds&limit=15Returns max 15 movies sorted by seeds (XML format). (Note: sort_by was 'sort' in original, corrected to 'sort_by')

Response Data Example (inside 'data' object):

Key NameDescriptionExample
movie_countThe total movie count results for your query2131
limitThe limit of results per page that has been set20
page_numberThe current page number you are viewing1
moviesAn array which will hold multiple movies and their relative information[...]

Movie Details

Returns the information about a specific movie.

HTTP Method: GET

Endpoints:

  • https://flixapi.gametrader.my/api/v2/movie_details.json
  • https://flixapi.gametrader.my/api/v2/movie_details.jsonp
  • https://flixapi.gametrader.my/api/v2/movie_details.xml

Parameters:

ParameterRequiredTypeDefaultDescription
movie_id or imdb_idYes (one of them)Integer (Unsigned)nullThe movie ID or the IMDB ID.
with_imagesNoBooleanfalseInclude image URLs in the response.
with_castNoBooleanfalseInclude cast information in the response.

Examples:

URLDescription
https://flixapi.gametrader.my/api/v2/movie_details.json?movie_id=10Returns basic information for movie ID 10.
https://flixapi.gametrader.my/api/v2/movie_details.json?movie_id=15&with_images=true&with_cast=trueReturns full information (images, cast) for movie ID 15.

Magnet URLs: See List Movies section for construction details and recommended trackers.

ParameterRequiredTypeDefaultDescription

Examples:

URLDescription
